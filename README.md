# Tugas-Double-Stack-Undo-Redo
# LAPORAN TUGAS
## Implementasi Double Stack Undo dan Redo

### 1. Tujuan
Memahami penggunaan struktur data stack untuk menjalankan fungsi Undo dan Redo dalam program Python.

### 2. Konsep
Stack adalah struktur data yang menggunakan prinsip Last In, First Out (LIFO), yaitu data yang terakhir dimasukkan akan menjadi data pertama yang dikeluarkan.

### 3. Implementasi
Program menggunakan dua stack:
- Undo Stack: menyimpan riwayat teks sebelumnya.
- Redo Stack: menyimpan perubahan yang dapat dikembalikan setelah Undo.

### 4. Fitur Program
- Menambahkan teks.
- Mengembalikan perubahan menggunakan Undo.
- Mengulangi perubahan menggunakan Redo.

### 5. Bahasa Pemrograman
Python

### 6. Repository
Kode program disimpan di GitHub dalam file `main.py`.
